# 流媒体服务

> 最后更新：2026-09-28

除本地音乐与在线 provider 外，SPlayer Atom 还支持由 Core 接入自建流媒体服务器，直接访问私有曲库。

## 支持的服务

| 类型            | 说明                                                                 |
| --------------- | -------------------------------------------------------------------- |
| **Subsonic 系** | Navidrome、OpenSubsonic、Airsonic、Gonic、LMS 等兼容 Subsonic 的服务 |
| **Jellyfin**    | 开源媒体服务器                                                       |
| **Emby**        | 媒体服务器                                                           |

> Subsonic 系服务共享同一套协议，差异仅体现在界面标签上。

## 添加服务器

1. 打开 **设置 → 媒体源配置**，开启「启用流媒体」总开关；
2. 新增一个服务器，选择类型（Navidrome / OpenSubsonic / Airsonic / Gonic / LMS / Subsonic / Jellyfin / Emby，共 8 种）；
3. 填写服务器地址、用户名与密码；
4. 保存后，若当前没有激活服务器（即添加第一台），会自动设为激活并尝试连接；已有激活服务器时新服务器不会自动连接，需手动切换。连接成功即可在侧边栏浏览该服务器的歌曲、专辑、歌手与歌单。

支持配置**多个服务器**并在它们之间切换；浏览数据会本地缓存，二次进入更快。

::: tip 凭据安全
服务器密码由 Core 编码后写入权限为 `0600` 的凭据文件；当前编码不提供静态加密，Base64 不等同于加密。Web Control 只读取不含密码的服务器配置。请保护 Core 主机及其数据目录。
:::

## 常见问题

- **连接失败**：检查服务器地址是否包含正确的协议（`http://` / `https://`）与端口，以及账号密码是否正确。
- **歌曲无法播放**：确认服务器本身可正常转码 / 直链，并检查网络是否可达。
