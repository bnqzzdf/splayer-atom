- UI restrictions are only transparency/preflight; native `[Direct]` rejection remains authoritative.
- Qobuz/TIDAL online Direct uses a local seekable input seam; the materializer preserves response bytes exactly and does not decode/transcode/resample.
- Real-account and real-DAC facts must never be claimed without observation.
