# SPlayer Atom 使用手册

> 最后更新：2026-10-26
>
> 适用版本：`1.1.3`（文档基线提交 `5693b3fc`）
>
> 读者：使用浏览器控制 SPlayer Atom 的最终用户

## 1. 这是什么

SPlayer Atom 由两部分组成：

- **Core**：运行在 Linux 音乐主机上的后台服务，负责曲库、队列、播放、缓存、下载、插件与所有账号；
- **Web Control**：浏览器里的控制界面。电脑、平板、手机都可以打开同一个地址。

关掉网页、刷新页面、换一台设备，都不会中断 Core 中正在播放的音乐。多个浏览器看到的是同一份队列、进度、输出设备与登录状态。

## 2. 第一次使用

### 2.1 打开界面

在浏览器访问：

```text
http://<Core 主机 IP>:14558
```

例如 Core 主机是 `192.168.1.20`，则打开 `http://192.168.1.20:14558`。

如果打不开：

- 确认 Core 服务已启动；
- 确认手机/电脑与 Core 在同一局域网；
- 确认防火墙放行 14558；
- 如果通过域名访问，管理员需要把域名加入 `ATOM_ALLOWED_HOSTS`。

### 2.2 引导页

首次使用可以打开：

```text
http://<Core 主机 IP>:14558/#/onboarding
```

引导页包含欢迎、语言/主题、曲库目录、流媒体说明四步。当前版本不会强制首访跳转；完成标记会保存在当前浏览器。

### 2.3 选择音频输出

第一次播放前必须先选择输出设备。没有选择时，Core 会返回 `OUTPUT_DEVICE_REQUIRED`，界面会弹出输出选择器。

输出分三组：

| 类型 | 说明 | 适合 |
| --- | --- | --- |
| ALSA | Core 主机的声卡/USB DAC | 直连 DAC 的主机 |
| Diretta | Diretta Target | 严格 HiFi 链路 |
| UPnP | 局域网 Renderer | 网络播放器、另一台音乐主机 |

选择后，Core 会记住偏好。播放中切换输出时，Core 会尝试重新加载当前曲目并恢复位置与播放状态。

### 2.4 添加曲库

1. 打开 **设置 → 本地曲库**。
2. 点击添加目录。
3. 目录选择发生在 **Core 主机** 上，不是浏览器所在设备。
4. 选择音乐目录后保存。
5. 点击增量扫描或全量扫描。

扫描进度会显示当前文件。一个 Core 同时只允许一个扫描；可以取消。

### 2.5 开始播放

进入 **歌曲**、**专辑**、**歌手** 或 **文件夹**，点击播放。播放栏会出现在底部。

## 3. 界面导览

### 3.1 侧边栏

常见入口：

- 首页
- 在线平台（至少登录一个平台后显示）
- 歌曲
- 我喜欢的音乐
- 播放历史
- 下载（启用后显示）
- 每日推荐（网易云登录后）
- 收藏（网易云登录后）
- 云盘（网易云登录后）
- 本地歌手 / 本地专辑
- 文件夹
- 流媒体
- 统计
- 搜索
- 设置

侧边栏支持分组、隐藏、排序与折叠；具体在 **设置 → 外观 → 侧边栏**。

### 3.2 播放栏

播放栏包含：

- 封面、标题、歌手；
- 上一首 / 播放暂停 / 下一首；
- 进度条与时间；
- 循环模式、随机；
- 音量；
- 输出设备；
- 队列；
- EQ、倍速/音调、A/B 循环、定时关闭、私人 FM；
- 全屏播放器入口。

手机上播放栏固定在底部，并适配安全区。

### 3.3 全屏播放器

点击封面或播放栏进入全屏播放器。它包含：

- 封面与歌词分栏；
- 歌词逐字/逐行显示、翻译、音译；
- 背景：模糊、纯色、流体动画；
- 队列面板；
- 收藏、评论、加入歌单、下载、打开所在文件夹；
- 歌词偏移调整；
- 全屏浏览器模式。

手机端默认先显示封面，点击封面切到歌词。

### 3.4 设置

设置弹窗左侧是分类，右侧是内容。顶部可以搜索设置项（整页自定义分类不参与搜索）。

分类通常包括：

- 外观
- 播放
- 歌词
- 本地曲库
- 网络与服务
- 媒体源配置
- 下载配置
- 本地与缓存
- 插件管理
- 其他设置
- 关于软件

## 4. 本地曲库

### 4.1 歌曲

歌曲页支持：

- 搜索标题、歌手、专辑、路径；
- 按标题、歌手、专辑、路径、时长、大小、修改时间、创建时间、音轨号排序；
- 批量选择；
- 播放全部；
- 批量加入队列、下载、加入歌单、移除；
- 编辑标签；
- 打开所在文件夹（本地文件）。

### 4.2 专辑与歌手

- **本地专辑**：按专辑聚合，可进入专辑详情；支持多碟筛选、按碟分组。
- **本地歌手**：按歌手聚合，可进入歌手详情。
- 专辑详情可“打开专辑所在目录”，会定位到 Core 主机上的真实目录；CUE/SACD 会定位到容器文件所在目录。

### 4.3 文件夹浏览

文件夹页直接浏览 Core 主机的文件系统，但只能浏览已加入曲库的扫描目录。

支持：

- 根目录与固定目录；
- 面包屑导航；
- 列表/网格视图；
- 按名称、修改时间、音轨号排序，升降序；
- 当前目录筛选；
- 递归搜索；
- 批量选择；
- 播放、随机播放、下一首播放、加入队列；
- 加入歌单；
- 扫描当前目录；
- 图片/PDF/文本预览；
- CUE/SACD 容器展开为分轨；
- 固定/取消固定目录。

文件夹操作**不会删除文件**。批量操作只影响队列与歌单。

### 4.4 CUE 与 SACD

- CUE 只支持单 FILE 的整轨 CUE；分轨会显示为独立曲目。
- SACD ISO 会展开为立体声分轨。
- 容器条目可以展开，单轨播放、下一首、入队、加入歌单。
- Direct 输出下 CUE 使用 75fps 精确边界，支持无缝；UPnP 下 CUE/SACD 会生成临时文件，首次播放可能稍慢。

### 4.5 标签编辑

在歌曲菜单选择“编辑标签”。可修改：

- 标题、歌手、专辑歌手、专辑；
- 流派、年份；
- 音轨号、碟号；
- 歌词；
- 封面（本地文件或 URL）。

说明：

- 只提交有变化的字段；
- 空字符串/0 表示清除；
- 如果编辑的是当前播放曲目，会先停止、写入、重新加载并恢复进度；
- 封面下载失败时只跳过封面，文本仍会写入；
- 只允许编辑曲库已知的文件。

### 4.6 我喜欢的音乐

- **本地红心**：对本地曲目标记喜欢，保存在 Core。
- **网易云红心**：需要网易云登录，读取账号红心。

两个 tab 的数据来源不同，不会互相同步。

## 5. 播放与队列

### 5.1 队列

队列由 Core 管理。可以：

- 播放全部；
- 下一首播放；
- 加入队列；
- 在队列中拖动排序；
- 移除单曲；
- 清空队列；
- 定位当前曲目；
- 查看剩余总时长。

多个浏览器看到同一队列。在任一浏览器修改，其他浏览器会收到更新。

### 5.2 循环与随机

| 模式 | 行为 |
| --- | --- |
| 循环关 | 播放到队尾后停止 |
| 列表循环 | 队尾回到第一首 |
| 单曲循环 | 当前曲结束后重载当前曲 |
| 随机开 | 当前曲保持在首位，其余随机；关闭随机恢复原顺序 |

注意：**上一首**在队列第一首时会环绕到队尾，即使循环关闭。这是当前行为。

### 5.3 自动下一首与失败跳过

- 正常结束会自动加载下一首。
- 单曲加载失败时，Core 最多尝试 `min(5, 队列长度)` 次。
- 设备类错误、未知错误不会自动跳过。
- 在线音源 URL 过期时，Core 会对同一首歌重新解析一次。
- 队列只有一首时，不会“跳到别的歌”。

### 5.4 预载与无缝

开启 **设置 → 播放 → 预载下一首** 后，Core 会提前解析下一首：

- ALSA Processed：在未使用 CUE/SACD/DSD、且变速/变调处于 bypass 时，可无缝衔接普通 PCM；
- ALSA Direct / Diretta：在后台准备下一首，同 wire-format 时无缝；
- UPnP：不支持 gapless，每首重新加载。

Diretta/ALSA Direct 即使未开启预载，也会尝试准备下一首。

### 5.5 定时关闭

播放栏菜单 → 定时关闭：

- 1～180 分钟；
- 预设 10/20/30/45/60/90/120；
- 可勾选“等当前歌曲结束”；
- 到点只暂停播放，不关闭 Core；
- 定时器只在本次 Core 运行期间有效，重启丢失。

### 5.6 A/B 循环

在全屏播放器或播放栏菜单打开 A/B 循环：

- 设置 A 点与 B 点；
- 到达 B 点自动跳回 A；
- 可清除。

### 5.7 倍速、音调、EQ、响度

这些属于“样本处理”，只在 **ALSA Processed** 输出下可用：

- 倍速 0.5～2.0；
- 音调 -12～+12 半音，可开启音调同步；
- 10 段 EQ + 前级；
- 响度均衡、削波保护、淡入淡出。

在 **ALSA Direct、Diretta、UPnP** 下，这些控件会被锁定，音量显示为 1。这是输出路径约束，不是故障。

### 5.8 私人 FM 与心动模式

- **私人 FM**：需要网易云登录。可选默认/熟悉/探索/场景模式。FM 模式下“下一首”变为“不喜欢”。
- **心动模式**：以当前网易云歌曲或随机红心歌曲为种子生成推荐队列。

FM 池、心动队列不持久化；Core 重启后回到普通队列。

## 6. 音频输出

### 6.1 ALSA

ALSA 设备来自 Core 主机的真实硬件端点：

- 设备名形如 `alsa:hw:CARD=xxx,DEV=0`；
- 不提供 `default`/`plughw`/`softvol`；
- HDMI/DisplayPort 端点默认隐藏，除非当前已选中。

ALSA 有两种模式：

| 模式 | 特点 | 可用处理 |
| --- | --- | --- |
| Processed | 日常使用；仅 mono/stereo；不做 ALSA 重采样 | EQ、响度、变速、变调、淡入淡出 |
| Direct | 保留有效位；整数不转 float；支持原生 DSD | 无样本处理 |

切换模式会让 Core 重新加载当前曲目；失败时可能停止播放，需要重新播放。

### 6.2 Diretta

Diretta 是严格 Source Direct：

- 需要 Core 以 root 运行；
- 需要构建时包含 Diretta SDK；
- 只接受无损整数 PCM 或原生 DSD；
- 同一次连接中下一首必须保持相同 wire-format；
- 不支持重采样、音量、EQ、变速、变调、DoP、DSD 转 PCM；
- 不支持的格式会直接报错，不会降级。

如果 Diretta 没有声音：

1. 确认输出选择的是 Diretta Target；
2. 确认 Core 以 root 运行；
3. 确认曲目是无损整数 PCM 或 DSD；
4. 确认 Target 未被其他 Host 占用；
5. 查看 Core 日志中的 `OUTPUT_FORMAT_UNSUPPORTED` 或其他错误。

### 6.3 UPnP

UPnP 输出到局域网 Renderer：

- 同一时间只支持一个 Renderer；
- 支持常见 PCM/DSD 格式，但多声道会被拒绝；
- 无 gapless；
- CUE/SACD 需要生成临时文件；
- Renderer 必须能访问 Core 主机的临时媒体端口。

如果设备列表为空，检查 Core 与 Renderer 是否在同一网段、SSDP 多播是否被防火墙拦截。

## 7. 在线音乐

### 7.1 支持平台

- 网易云音乐
- QQ 音乐
- 酷狗音乐
- Qobuz
- TIDAL

### 7.2 登录方式

| 平台 | 方式 |
| --- | --- |
| 网易云 | 扫码；或手动粘贴 Cookie |
| QQ 音乐 | QQ 扫码 / 微信扫码；或手动 Cookie |
| 酷狗 | 扫码；或手动 Cookie |
| Qobuz | 浏览器 OAuth；或手动粘贴 token |
| TIDAL | 官方 PKCE 回调；或设备码；或手动 token |

说明：

- Core 保存登录信息，Web 只看到“已登录/未登录”与账号名，不返回 Cookie/token。
- 手动登录时，Cookie/token 会经过浏览器表单，再发给 Core。
- TIDAL 设备码通常只有 AAC；需要无损时使用官方 PKCE。
- Qobuz 非订阅账号可能只返回试听片段。

### 7.3 平台首页

登录后侧边栏出现“在线平台”。平台首页包含：

- Qobuz/TIDAL 的分区与流派；
- 网易云/QQ/酷狗的榜单、新歌、新碟、热门歌手、推荐歌单；
- 点击条目进入专辑/歌单/榜单/歌手详情；
- “查看全部”进入平台分区页。

### 7.4 每日推荐、收藏、云盘

- **每日推荐**：网易云，按 6:00 逻辑日归档最近 14 天。
- **收藏**：网易云的歌单/专辑/歌手。
- **云盘**：网易云云盘曲目、容量与删除云盘歌曲。

这些功能都需要网易云登录。

### 7.5 试听与权益

在线歌曲可能遇到：

- 需要会员（VIP）；
- 需要购买数字单曲/专辑；
- 只有试听片段；
- 该地区/账号不可用；
- 需要重新登录。

Web 会显示对应的错误提示。开启“允许试听”后，只有试听源的歌曲会播放片段；试听源不会进入歌曲缓存。

## 8. 自建媒体服务器

支持类型：

- Subsonic
- Navidrome
- OpenSubsonic
- Airsonic
- Gonic
- LMS
- Jellyfin
- Emby

添加步骤：

1. 设置 → 媒体源配置 → 流媒体服务器。
2. 新增服务器：名称、类型、URL、用户名、密码。
3. 测试连接。
4. 保存并设为激活。
5. Core 会自动拉取媒体库快照；也可以手动同步。

浏览：

- 流媒体页有歌曲/专辑/歌手/歌单四类；
- 支持搜索、播放全部；
- 专辑/歌单/歌手详情复用合集/歌手页；
- 歌词由服务器提供。

注意：

- 同一服务器同步是单飞的；首次同步可能较慢。
- 同步失败会保留上一次快照。
- 删除服务器会删除 Core 中该服务器的快照数据，不影响服务器本身。

## 9. 搜索

搜索页支持三类来源：

1. **本地**：歌曲、专辑、歌手；
2. **流媒体**：已激活的媒体服务器；
3. **在线平台**：已登录且 Core 支持的平台。

行为：

- 歌曲/专辑/歌手/歌单四个 tab；
- 每页 50 条，滚动加载；
- 切换关键词/平台/服务器会丢弃旧请求；
- 认证失败会显示登录入口；
- 头部搜索弹窗支持搜索历史、热搜、建议与网易云链接解析。

## 10. 歌词

### 10.1 支持格式

LRC、QRC、YRC、KRC、TTML、LyS、SRT、ASS。支持逐字、翻译、音译、双语显示。

### 10.2 来源

- 本地文件内嵌歌词；
- 同名外挂歌词；
- 在线平台歌词；
- 插件歌词；
- AMLL TTML（在线或本地库）。

来源优先级可在 **设置 → 歌词 → 来源顺序/格式顺序** 调整。

### 10.3 歌词偏移

全屏播放器歌词工具栏可以：

- 提前/延后 500ms；
- 直接输入偏移；
- 重置。

偏移按“曲目 + 歌词源”保存，范围 ±60 秒。正值为歌词提前。

### 10.4 本地 TTML 歌词库

设置 → 歌词 → 本地 TTML：

- 指定 Core 主机上的目录；
- Core 递归扫描 `.ttml`；
- 通过 AMLL 元数据（网易云/QQ ID、标题、艺术家）匹配。

注意：索引只检查根目录 mtime；在子目录新增/删除文件可能不会自动重建。可变更目录或重启 Core 触发。

### 10.5 歌词显示

可调：

- 引擎：physics / AMLL；
- 字号、字重、字体；
- 翻译、音译；
- 逐字高亮、上浮、强调、模糊；
- 隐藏已播放行；
- 弹簧参数、对齐位置、渐变宽度、非激活透明度；
- 背景歌词识别；
- 排除关键词/正则。

AMLL 与流体背景资源占用较高；低性能设备建议使用 physics + 模糊背景。

## 11. 歌单

### 11.1 本地歌单

- 新建、改名、描述、删除；
- 添加/移除歌曲；
- 清空；
- 封面自动取第一首新增歌曲的封面（若歌单无封面）。

本地歌单保存在 Core，不属于浏览器本地数据。

### 11.2 网易云歌单

需要网易云登录：

- 创建（可设隐私）；
- 改名/描述；
- 删除；
- 加歌/移除；
- 收藏/取消收藏。

受账号权益与平台限制。

### 11.3 侧边栏歌单

侧边栏“我的歌单”可切换本地/在线来源，支持封面、分组、隐藏与排序。

## 12. 下载

### 12.1 启用

设置 → 下载配置 → 打开“启用下载”。关闭时所有下载入口隐藏。

### 12.2 下载设置

| 设置 | 说明 |
| --- | --- |
| 下载目录 | Core 主机上的目录；默认 `~/Music/SPlayer Atom Core` |
| 音质 | hi-res / lossless / hq / sq / lq；默认 lossless |
| 使用播放接口下载 | 网易云可选，失败时作为替代路径 |
| 文件名模板 | `{title}` / `{artist} - {title}` / `{title} - {artist}` |
| 分文件夹 | 不分 / 按专辑 / 按专辑+碟 |
| 重名策略 | 重命名 / 覆盖 / 跳过 |
| 歌词格式 | LRC / 增强 LRC |
| 内嵌封面/元信息/歌词 | 可选 |
| 额外写 LRC/TTML | 可选 |

### 12.3 下载任务

下载页有三个 tab：

- 进行中
- 失败
- 已完成

说明：

- 下载串行，一次一首；
- 同曲同音质会去重；
- 无断点续传；
- 临时文件在缓存目录，启动时清理；
- 取消/删除任务不会删除已完成的音乐文件；
- 已完成任务可以直接播放本地文件。

## 13. 缓存

缓存分两类：

| 类型 | 内容 | 位置 |
| --- | --- | --- |
| 文件缓存 | 封面、歌手图、背景、歌曲缓存 | Core 缓存目录 |
| 数据库缓存 | 歌词、TTML、歌词匹配 | `library.db` |

设置 → 本地与缓存：

- 查看各类占用；
- 分类清理；
- 切换缓存目录（目标必须为空）；
- 恢复默认缓存目录；
- 全部清理。

说明：

- 歌曲缓存默认关闭；开启后可设上限（默认 10 GB）。
- 图片缓存没有自动上限，建议定期清理。
- 切换缓存目录会清空旧的文件类缓存，不会迁移。
- 数据库缓存不受目录切换影响。

## 14. 插件

### 14.1 安装

设置 → 插件管理 → 从 URL 安装。只接受：

- HTTPS；
- 或 `http://localhost` / `http://127.0.0.1`。

安装的是插件脚本（`.js`），不是压缩包。

### 14.2 类型与权限

| 类型 | 作用 | 默认权限 |
| --- | --- | --- |
| 音源插件 | 提供播放 URL、歌词、封面 | 自动 `network` |
| 控制插件 | 控制播放器、设置项、歌曲菜单 | 需声明 `network` / `control` / `ui` |

### 14.3 管理

- 启用/禁用；
- 查看状态（loading/ready/error/disabled）；
- 配置插件设置；
- 检查更新、一键更新；
- 卸载（删除脚本与插件数据）。

### 14.4 安全提醒

- 插件是第三方代码，可联网；
- 只安装可信来源；
- 插件运行在 Core 的隔离子进程，但不是强安全沙箱；
- 一个插件长时间阻塞会拖住其他插件；
- host 崩溃会自动重启，超过次数后插件置 error。

## 15. 统计与历史

### 15.1 统计

统计页数据来自 Core：

- 曲库概览：歌曲/专辑/歌手/总时长/总大小；
- 最近 90 天热力图；
- 时段分布；
- 音质构成；
- 最常听歌曲/专辑/歌手。

Top 榜排除 `streaming` 来源；summary/daily/hourly 包含所有来源。

### 15.2 播放历史

“播放历史”是**当前浏览器本地**的记录：

- 最多 500 条；
- 去重、倒序；
- 可删除/清空；
- 不同步到其他设备。

它和 Core 的统计是两套数据。

## 16. ListenBrainz

设置 → 网络与服务 → ListenBrainz：

1. 打开总开关；
2. 粘贴 ListenBrainz token；
3. 绑定账号；
4. 可选择是否发送 Now Playing。

说明：

- 关闭时不做任何后台上报；
- 上报在独立子进程，不阻塞播放；
- 阈值约为曲目时长的一半，最多 240 秒；
- 可在面板查看 pending/dead 与清空 outbox。

## 17. 多设备使用

- 多个浏览器可以同时连接同一个 Core。
- 队列、当前曲目、循环/随机、输出设备、登录状态由 Core 共享。
- 浏览器本地设置（主题、布局、字体、歌词显示、界面缩放）不共享。
- 播放历史不共享。
- 关闭浏览器不会停止播放；重新打开会从 Core 恢复当前状态。

如果两个设备同时操作队列，以 Core 收到的命令顺序为准；后到的修改会覆盖先到的修改。

## 19. 常见问题

### 19.1 没有声音

1. 确认已选择输出设备。
2. 确认输出设备不是被其他程序独占。
3. Diretta：确认 root、Target 未被占用、源格式受支持。
4. UPnP：确认 Renderer 能访问 Core 的媒体端口。
5. ALSA：`aplay -l` 是否仍能看到设备。
6. 查看 Core 日志中的错误码。

### 19.2 提示“需要选择输出设备”

打开播放栏的输出选择器，选择 ALSA/Diretta/UPnP 设备。选择后重新播放。

### 19.3 提示“当前输出不支持该格式”

通常发生在 Diretta 或 Direct ALSA：

- 源不是无损整数 PCM/DSD；
- 下一首与当前 wire-format 不一致；
- 多声道/浮点源。

换一首歌、换输出，或改用 Processed（会失去严格性）。Diretta 不会自动降级。

### 19.4 浏览器 403

可能是：

- 通过域名访问但未加入 `ATOM_ALLOWED_HOSTS`；
- 反向代理改写了 Host；
- 使用了 `file://` 或 sandbox iframe。

联系管理员检查 Host/Origin 配置。

### 19.5 歌词不显示

- 检查歌词来源顺序与格式顺序；
- 在线歌词需要平台登录或网络；
- 本地文件可能没有内嵌歌词；
- 可在歌曲菜单尝试“匹配歌词”；
- 检查是否被排除规则过滤。

### 19.6 下载入口不见了

下载默认关闭。到 **设置 → 下载配置** 打开“启用下载”。

### 19.7 下载很慢/失败

- 下载是串行的，一次一首；
- 无断点续传；
- 在线平台可能限速或需要权益；
- 磁盘空间不足会失败；
- 失败任务可在下载页查看。

### 19.8 插件显示 error

- 查看插件卡片的错误信息；
- 确认脚本声明了正确的 `@apiLevel` 与权限；
- 禁用后重新启用；
- host 崩溃会自动重启，超过次数后需要手动启用；
- 只安装可信来源插件。

### 19.9 曲库为空

- 确认扫描目录在 Core 主机上存在且可读；
- 确认扫描已完成；
- 检查目录是否被移除；
- 大库首次扫描需要时间；
- 查看 `library count` 与扫描进度。

### 19.10 多设备状态不同步

- 确认所有设备连接的是同一个 Core；
- 刷新页面，等待 WebSocket 重连；
- 检查是否有一台设备处于离线缓存状态；
- 主题/布局/历史本来就不同步。

### 19.11 统计和播放历史不一致

统计来自 Core，历史来自当前浏览器 IndexedDB；两者口径与范围不同，不是同一份数据。

## 20. 数据与隐私

- 曲库、设置、歌单、统计、下载任务、登录状态都在 Core 主机。
- 浏览器本地只保存显示偏好、播放历史、部分平台缓存。
- Core 无鉴权、无 TLS；只应在可信局域网使用。
- 凭据文件权限为 0600，但编码不是加密；备份需保护。
- Atom 不删除音乐文件；清理只涉及缓存、临时文件与未完成下载。
- 卸载/删除 `data/` 会丢失曲库索引、设置、歌单、统计与登录状态。

## 21. 键盘与移动端

### 21.1 键盘

当前版本**没有全局播放快捷键**。可用的键盘交互主要是：

- 头部搜索弹窗：上下键移动、回车执行；
- 输入框：回车提交、Esc 取消；
- 复选框/单选框：空格或回车切换；
- 数字输入：回车确认、Esc 取消。

### 21.2 移动端

- 手机使用抽屉导航与固定底部播放栏；
- 全屏播放器默认显示封面，点击切歌词；
- 音量改为点击展开面板；
- 设置弹窗为全屏两视图；
- 支持安全区与动态视口高度；
- 建议横屏/大屏使用完整布局。
