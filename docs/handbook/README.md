## 事实来源与口径

本套文档以**代码实际行为**为第一优先级，其次才是既有文档的描述。编写时遵循以下口径：

1. 版本、schema、端口、默认值以仓库代码为准；文档中给出 `file:line` 或文件名，便于复核。
2. 标为“已实现”的功能表示代码与自动测试存在；标为“待验收”表示仍需要真实硬件、真实账号或目标浏览器的一次记录运行。
3. 已知与设计冲突、文档过期或接口缺陷会明确写入“已知限制”，不会用模糊措辞掩盖。
4. 单位统一在 Core/Web 边界说明：对外时间字段为毫秒，音量 `0..1`，速度是倍率，自动关闭时长为分钟。
